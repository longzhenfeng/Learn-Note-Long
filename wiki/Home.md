# Learn Note Long Wiki

欢迎来到 Learn Note Long 项目的 Wiki！

## 📚 项目简介

Learn Note Long 是一个全栈开发学习笔记项目，记录了 Node.js、Express 和 Vite 等技术的学习历程和实战经验。

### 在线文档

🌐 **访问地址**: [https://longzhenfeng.github.io/Learn-Note-Long/](https://longzhenfeng.github.io/Learn-Note-Long/)

### 项目特点

- 📖 **系统化学习笔记** - 涵盖后端和前端技术栈
- 🎨 **Cyber Wave 主题** - 采用优雅的青色主题设计
- 🌓 **深色模式支持** - 支持亮色/暗色主题切换
- 🚀 **自动化部署** - 基于 GitHub Actions 的 CI/CD
- 💡 **实战导向** - 包含大量代码示例和最佳实践
